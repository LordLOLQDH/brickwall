# BRICKWALL

**Das hobbyloseste, komplizierteste und absichtlich schlechteste Backstein-GUI.**

BRICKWALL ist eine kleine, statische Browser-Anwendung, die schlechte Bedienbarkeit parodiert: Backsteinmuster, überladene Panels, verwirrende Navigation, nutzlose Meldungen und überflüssige Verwaltungsprozesse.

## Starten
Öffne `index.html` in einem Browser oder veröffentliche das Repository über GitHub Pages.

## Funktionen
- Responsive, absichtlich überladene Backstein-Oberfläche
- Navigation, die den Inhalt umständlich ersetzt
- Lokales Demo-Formular ohne Versand oder dauerhafte Speicherung
- Aufgaben-Zähler, Ereignisprotokoll und lokale Support-Tickets
- Panikmodus und absichtlich nutzlose Statistiken
- Keine externen Bibliotheken, kein Tracking und keine Netzwerk-API

## Datenschutz
Formulare werden nicht an einen Server übertragen. Inhalte werden nicht dauerhaft gespeichert. Ein Neuladen setzt den lokalen Zustand zurück.
